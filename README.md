# homebrew-tap

Homebrew tap for [fmeinhold](https://github.com/fmeinhold)'s tools.

```sh
brew install fmeinhold/tap/wo
```

| Formula | What it is |
| --- | --- |
| [`wo`](https://github.com/fmeinhold/working-on) | Track what you're working on from the command line, with toggl track |

Casks in this tap are generated by [GoReleaser](https://goreleaser.com) from each
tool's release pipeline — edit them there, not here.
